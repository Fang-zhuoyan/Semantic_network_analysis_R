# Semantic_network_analysis_R
本仓库包含用于论文《让物理观念“看得见”：基于语义网络分析的高中生“力与运动”知识结构差异研究》的 R 语言代码以及构建语义网络部分的补充说明。
'install and process' 为主要脚本文件，
《“力与运动”主题下的语义网络构建过程》为正文中关于构建语义网络部分的补充说明。

## 使用说明
详细的使用方法和说明，请参考论文正文以及补充说明。

## 依赖环境
- R 版本 ： 4.5.0
- RStudio 版本 ： 2024.12.0+467
- Rtools 45
- 必要 R 包：
  - readr
  - SemNetCleaner
  - SemNeT
  - SemNetDictionaries
